# SHARek Web App (`/app/`)

نسخة الويب من تطبيق شارك، تُنشر ضمن موقع `sharek.space` على المسار `/app/`. تستخدم **نفس قاعدة بيانات Supabase ونفس الـ Edge Functions** التي يستخدمها تطبيق الأندرويد، فالحسابات والوجبات والمحادثات واحدة في الاثنين.

- الصفحات الثابتة (`/` و `/privacy/` و `/terms/` و `/delete-account/` و `/meals/...` و `.well-known`) تبقى كما هي في جذر الموقع.
- `npm run build` في جذر `sharek-site` يبني هذا التطبيق ويجمع كل شيء في `dist/`، وVercel ينشر `dist/` تلقائيًا (راجع `vercel.json`).
- القيم العامة (رابط Supabase والمفتاح العام anon ومفتاح VAPID العام) موجودة في `.env.production`. هذه القيم تظهر في كود المتصفح أصلًا. **لا تضع أبدًا مفتاح `service_role` هنا.**

## التشغيل محليًا

```bash
npm install
npm run dev
```

## مزامنة التحديثات مع تطبيق الموبايل

الكود منسوخ من `SharekApp/project/src`. عند تعديل التطبيق، انسخ التغييرات إلى `src` هنا. الفرق الوحيد أن الصور وملف الإشعارات تستخدم `import.meta.env.BASE_URL` بدل `/` لأن التطبيق يعمل تحت `/app/`.
